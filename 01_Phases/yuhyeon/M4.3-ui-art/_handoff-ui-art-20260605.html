⚠️ 헌법 #1 (Server Authority) — 모든 UI는 서버가 알려준 값을 표시만 합니다. HP/MP/EXP/Gold/퀘스트 진행도 계산은 절대 클라 UI 코드에 넣지 않습니다. 기존 HudController가 이 패턴의 본보기: 패킷 핸들러가 UpdateHP(current, max)를 호출하는 구조입니다.

1️⃣ 캐릭터 Status — HP / MP / EXP MP·EXP 연결 필요

HUD > status_hud
Art/UI/UI_files/1_status_hud_frame.png — 프레임
knight_icon.png — status_icon1
character_icon2.png — status_icon2
오브젝트컴포넌트현재 상태
HpSliderSlider (Fill = 내장 white)✅ HudController._hpSlider에 연결, mock 100/100
MpSliderSlider⬜ 미연결 — 인스펙터 참조도 없음
ExpSliderSlider⬜ 미연결 — 인스펙터 참조도 없음
HpTextTMP (HUD 직속)⬜ 비활성 상태, "HP 100 / 100"
구현 가이드 (팀장)
  • Scripts/UI/HudController.cs에 UpdateMP(int, int) / UpdateEXP(long, long) 추가 — 기존 UpdateHP 패턴 복붙 수준
  • 인스펙터에서 MpSlider/ExpSlider SerializeField 연결
  • Fill 이미지가 내장 white라 색만 지정하면 됨 (HP 빨강 / MP 파랑 / EXP 노랑 등)
  • 서버 패킷 (예: StatSnapshot) 수신 핸들러 → Update* 호출. 패킷 신설 필요 시 PDL.xml append-only + Protocol.Version bump (헌법 #2)
