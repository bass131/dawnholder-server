# 문서 정비와 AI 작업 준비도 개선

상태: 문서 정비·독립 검증·보고서 작성 완료. [PR128](https://github.com/bass131/dawnholder-server/pull/128)을 생성했으며 상태는 OPEN·미병합이다. 병합 승인은 없다. 각 PR 병합 직전에 사용자 명시 승인을 받아야 한다.

## 목표와 범위

- 저장소 문서를 전수 조사하여 현재 지침, 게임 설계·기술 근거, 작업 이력, 중복·오래된 안내를 구분한다.
- 영역별 작업 이력은 보관 경로에 모으고, 현재 작업에 필요한 문서는 압축한다. 보존할 근거와 이동 후 링크를 확인한 뒤 파일을 옮긴다.
- 현행 문서의 모호한 표현, 과장, 불필요한 반복과 AI 특유의 문체를 읽기 쉬운 문장으로 정리한다.
- 변경 전에 고정한 평가 기준과 같은 과제로 개선 전후의 AI 작업 준비도를 비교한다. 실제 확인 결과와 문서 해석에 따른 평가를 구분한다.
- 평가에서 드러난 문서·운영 지침의 문제를 개선하고, 결과·근거·남은 문제를 반영한 HTML 보고서를 작성한다.
- 검증된 변경을 PR로 올린다. PR 생성 권한은 병합 권한이 아니다.

게임 코드·Unity 에셋·DB 변경, 사용자 전역 설정, 추가 운영 프로그램 개발은 이 문서 정비의 범위에 포함하지 않는다. 필요한 범위 변경은 메인이 사용자와 결정한다.

## 권한과 작업 분담

- 메인은 목표·평가 범위·파일 소유권·통합과 사용자 대화를 맡는다. 작업자는 할당된 범위만 수정한다.
- 문서 이동은 현황 조사 후 지정된 담당자가 수행한다. 조사와 평가 중인 파일을 임의로 옮기지 않는다.
- PR 생성은 허용한다. 각 PR 병합 직전 사용자 명시 승인을 받아야 하며, 이전 포괄 승인이나 메인의 판단으로 대체하지 않는다. 자동 병합 예약과 작업자의 임의 병합은 금지한다.
- 원문 로그와 상세 평가 자료는 별도 근거 파일에 두고 이 문서에는 판단과 결과를 요약한다.

## 평가와 결과

- 최초 문서 조사: 추적 문서 590개를 분류했다. 현재 기술 문서와 작업 이력을 분리하고 여섯 관심 영역에 44개 이력 요약과 7개 색인을 구성했다.
- [원문 매니페스트](../../../00_Document/archive/source-manifest.json)는 502건을 고정 커밋의 원문·SHA-256·요약 경로로 연결한다. 500건은 압축했고 현재 보고서 2건은 경로를 유지했다. 옛 운영 ADR 13건은 보관하되 기술 ADR 본문을 유지했다.
- [고정 평가 기준](../../../00_Document/evaluations/ai-readiness/method.md)은 공개 ai-readiness-cartography v2의 동일 배점을 전후에 적용했다. 원본 자동 점수는 17→40, 근거 보강 점수는 63→83으로 저자가 정한 목표 75점을 충족했다. 공인 인증이 아니며 평가자의 근거 판단을 포함한다.
- 개선 후 배점: A 15/15, B 18/20, C 20/20, D 15/15, E 12/15, F 3/10, G 0/5. 원본 자동 F의 복사 시각 효과는 보강 점수에서 제외했다. 시간·토큰 절감이나 대표 AI 작업 성공률을 실측한 결과가 아니다.
- [문서량 비교](../../../00_Document/evaluations/ai-readiness/document-metrics.json)는 같은 Markdown·HTML 범위에서 보고서 2개와 평가 산출물을 제외하고 UTF-8·LF로 맞췄다. 본문과 추적용 JSON 용량을 따로 기록했다.
- [개선 전](../../../00_Document/evaluations/ai-readiness/baseline.json)과 [개선 후](../../../00_Document/evaluations/ai-readiness/after.json)에 분야별 근거와 남은 문제를 보관했다.
