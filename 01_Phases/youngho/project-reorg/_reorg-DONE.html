📌 TL;DR

영호 "모든 프로젝트 UltraCode 실측해 깔끔하게 정리" → 7-에이전트 워크플로우로 전체 repo 실측. 핵심 발견: "정보 파편화"의 진짜 원인은 폴더 위치가 아니라 (1) 깨진 상대링크 ~60건 + (2) 마스터 INDEX 부재. 폴더는 이미 카테고리별로 잘 나뉘어 있고, 이동하면 frozen 문서(ADR/-DONE/정책)가 참조하던 경로가 깨진다. 따라서 "이동 최소화 + 비파괴 최대화" — 깨진 링크 depth별 일괄 수정 + 마스터/reviews INDEX 신설 + 미사용 정리(learning-journal 삭제·M4-backlog archive·state 백업 제거). 게임/기술 코드 0 변경.
