Chapter 7

테스트 & 결과

이 페이지에서 배울 것
코드가 정말 의도대로 동작하는지 어떻게 확신할까요? 이 페이지에서는 작성한 단위 테스트 8건이 각각 무엇을 검증하는지, 특히 핵 차단의 핵심인 경계값(diff=4 통과 vs diff=5 차단)을 어떻게 못 박았는지, 그리고 최종 결과와 코드 리뷰 통과 내역을 봅니다. 마지막으로 면접에서 이 작업을 설명할 핵심 3가지로 마무리합니다.

지연 보상 테스트 5건 — LagCompensationTests

되감기 범위 검증이 정확히 작동하는지를 시점 번호의 차이(diff)별로 검사합니다.

테스트무엇을 검증결과
Rewind_HappyPathdiff=0 (현재 틱 공격) → 정상 명중hit
Rewind_OutOfRange_4Tickdiff=4 (허용 최대 경계값) → 되감기 통과 + 명중hit
Rewind_BeyondRangediff=5 (200ms 초과) → silent drop, HP 변화 없음drop
Rewind_NegativeTicktick=-1 (음수) → silent dropdrop
Rewind_FutureTicktick=999 (미래) → silent dropdrop

Hitbox 테스트 3건 — HitboxTests

AABB 박스 교차 판정의 기하학적 정확성을 검사합니다. 순수 기하 연산이라 IO나 서버 의존 없이 빠르게 돌아갑니다.

테스트무엇을 검증결과
AABB_Intersects_HappyPath겹치는 두 박스 → Intersects=true (대칭성 포함)true
AABB_NoIntersect_OutOfRange분리된 두 박스 → Intersects=falsefalse
AABB_EdgeContact경계 접촉 → Intersects=true (≤ 비교 정책)true

핵심 경계값 — diff=4 hit vs diff=5 drop

이 한 틱의 차이가 "공정성과 핵 차단의 경계선"입니다. 테스트는 ring buffer가 회전하며 슬롯이 덮어써지는 과정까지 추적해, diff=4까지는 데이터가 살아 있어 명중하고 diff=5에서는 검증에 걸려 차단됨을 확인합니다.

diff가 4까지는 허용(hit), 5부터는 차단(drop). ring buffer 깊이 4슬롯과 검증 경계 >4가 정확히 맞물린다.

통합 테스트 + 봇 지연 시뮬

단위 테스트 외에, 실제 서버를 띄우고 헤드리스 봇(headless bot, 화면 없이 도는 테스트용 클라)으로 지연 환경을 시뮬레이션했습니다.

  • 200ms(4틱) 지연 — 적 HP 30에 한 대당 10 데미지이므로, 되감기가 제대로 작동하면 정확히 3대에 처치됩니다. 정합 확인.
  • 250ms(5틱) 지연 — 허용 범위(200ms)를 넘으므로 공격이 silent drop되어 적 HP가 줄지 않습니다. 핵 차단(범위 초과) 정합 확인.

"신뢰 경계를 시점 인덱스에만 둔 설계가 상용 FPS(Valve lag compensation)의 정석 패턴"이라는 평가를 받았습니다. untrusted 입력의 표면적을 정수 하나(틱 번호)로 최소화하고, 위치는 서버가 직접 보유한 것만 쓰도록 한 점이 핵심입니다.

마무리 — 면접에서 말할 핵심 3가지

POINT 1

lag compensation의 본질

지연 때문에 "맞췄는데 빗나가는" 불공정을, 서버 권위를 유지한 채 공격 시점으로 되감아 해결했다. Source/Quake/Overwatch가 쓰는 정석 패턴.

POINT 2

시점 인덱스만 신뢰

클라는 좌표가 아니라 틱 번호만 보낸다. 위치는 서버 ring buffer에서 꺼낸다. 신뢰해야 할 입력을 정수 하나로 최소화해 텔레포트 핵을 원천 봉쇄.

POINT 3

fail-closed cheat 차단

음수·미래·범위 초과를 3분기로 검사해 조용히 버린다(silent drop). 되감기 범위를 200ms로 제한한 것이 공정성과 핵 차단을 양립시킨 열쇠.

🎓 한 문장으로

"200ms 지연 환경에서 ring buffer 기반 되감기로 공정한 hit 판정을 구현하되, 클라가 보내는 시점 인덱스를 fail-closed로 검증해 핵을 막고, AABB 박스 교차로 정밀도를 올린 서버 권위 전투 시스템을 만들었습니다."
