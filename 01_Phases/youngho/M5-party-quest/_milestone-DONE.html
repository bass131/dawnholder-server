🎯 무엇을 만들었나

영호 Play-test 동선에서 빠진 콘텐츠 7종을 한 마일스톤으로 묶었습니다. 핵심은 파티 + 퀘스트 + 게이트 — 프로젝트 첫 플레이어 간 협동 시스템이며, 신규 프로토콜 ProtocolVersion v14→v15(비가역 bump, 8패킷)가 걸렸습니다.

  • 파티 시스템 — 초대/수락, 정원 2명 고정, cross-map(마을↔헌팅) 유지.
  • 40킬 공유 퀘스트 — 파티원 합산 킬카운트 + S_QuestUpdate 진행 통보(양 멤버).
  • 보스 포탈 잠금 게이트 — 40킬 미달 시 BossRoom 진입 거부(서버 권위, ghost 방지, fail-closed).
  • 양방향 포탈 — 진입 = 충돌 자동 → "겹침 + 위 방향키 down-edge", 역방향 데이터 추가.
  • 일반몹 공격 — 보스만 공격하던 것을 Normal/Golem도 사거리 내 공격(쿨다운 기반).
  • 이펙트 결선 — 일반몹 kind별 피격 이펙트 라우팅 + 보스 stab 결선 실측.
  • StageClear 애니 — TMP 텍스트 → Image 애니 스프라이트(swap-ready).

🤔 왜 이렇게 — 핵심 설계 결정 + trade-off

1. PartyRegistry = GameWorld 소유 actor (맵/세션 아님)

파티는 cross-map(멤버가 서로 다른 맵에 있어도 유지)이라 특정 맵/세션에 둘 수 없습니다. EnqueueJob + 매 틱 드레인(lock 금지, 헌법 actor 정합). 멤버 식별 = entityId(session 참조 X → disconnect race 회피, ADR-026).
단점: GameWorld 책임 증가. vs 맵 소유(❌ cross-map 깨짐) / lock dict(❌ 헌법 위반).

2. 보스 게이트 = MapMigration.Execute 검증단계 (transfer 전)

RemovePlayer/SetMigrating 전에 portal.Dest==BossRoom && killCount<40 차단 → 거부 시 원래 맵 잔류(ghost 0). killCount=서버 권위(PartyRegistry.GetKillCount), 행위자=서버 _entityId(패킷 값 X), fail-closed(GameWorld null → 0킬 → 거부).
trust-boundary → reviewer 🔴0. vs transfer 후 검증(❌ 어느 맵에도 없는 ghost).

3. QuestConstants.BossUnlockKillCount=40 = 서버측 배치 (98_Shared 아님)

targetCount를 S_QuestUpdate 패킷에 실어 보내 진짜 SSOT는 wire — 클라는 패킷값만 표시(하드코딩 0). 서버측 배치로 불필요한 Shared.dll co-review를 회피해 야간 헤드리스 완주 유지.
서버 권위(헌법 §1)의 작은 실천 — 클라는 렌더러.

4. C1 ApplyMeleeDamage 헬퍼 추출 — 순수 서버, 98_Shared 무변경

보스/일반몹 공통 데미지 경로를 헬퍼로 추출(보스 ApplyBossAttack 본문 byte-identical 이식 → 보스 동작 회귀 0, 보스 테스트 전건 green이 가드). EnemyStats.Attack(Normal 5/Golem 8) 기존 재사용 + S_EnemyAttack(ID20) 재사용 = 신규 패킷 0, ProtocolVersion bump 0, 98_Shared 무변경.
Extract Method로 회귀 위험을 테스트로 봉인. vs 복붙(❌) / 새 패킷(❌ v15 충돌).

5. 봇 e2e = in-process 시드 하이브리드

40킬 실 그라인드는 리스폰 100틱(5초)·HG 적 제한으로 60~90s 느림/flaky. 게이트·공유전달 e2e는 ServerFixture in-process 시드(killCount 충족, 게이트는 서버 권위값 실검사 → 정당 통과)로 검증. 킬→카운트 wiring은 Q2 xUnit이 별도 검증. 봇 근접전투(위치/serverTick/aggro) finicky → R1을 시드로 재설계.
동일 결과를 빠르고 robust하게. 풀 40킬은 아침 play-test. MapTransition 회귀도 seedBossGate 훅으로 봉합.
