🎯 무엇을 했나 — "이름이 거짓말하지 않는 구조"

코드는 한 줄도 거동이 바뀌지 않았고(behavior-invariant), 대신 폴더·네임스페이스·데이터 경계를 정리해 M8(DB 영속화)이 깨끗한 토대 위에 붙도록 했습니다. 핵심은 "사람이 이름을 보고 위치를 예측할 수 있게"(ADR-033).

BEFORE — 이름이 거짓말하던 곳
GameServer/Network/ # 3중 오버로드 GameSession.cs (NS=Sessions인데 폴더=Network) IntentRateLimiter.cs MapMigration.cs (네트워크 아닌 존이동) Maps/PlayerEntity.cs # 자매 엔티티가 Combat/EnemyEntity.cs # 두 폴더에 흩어짐 Combat/EnemyState.cs Maps/Systems/*.cs (폴더=Systems, NS=Maps)
→
AFTER — 폴더 = 개념 = 네임스페이스
Sessions/ GameSession.cs · IntentRateLimiter.cs Maps/Transitions/ MapMigration.cs (존 이동 정위치) Entities/ # 엔티티 통합 PlayerEntity.cs · EnemyEntity.cs EnemyState.cs (M8 저장 추상화 토대) Combat/ (CombatConstants·EnemyCatalog·Hitbox 잔류) Maps/Systems/* NS=...Maps.Systems 정합
