1. 무엇이 바뀌었나 — 한눈에

Unity 씬 저작타일맵 + 마커 (저작 도구일 뿐)
→
TerrainBaker에디터 bake (idempotent)
→
terrain.bin / content.binDWMP + CRC32 fail-closed
→
서버 · 클라 · 봇같은 파일 + 같은 Physics.Step = desync 0
파일 경계 = 신뢰 경계 (헌법 #1) — terrain.bin(솔리드/발판/kill-plane)은 3경로 공유, content.bin(플레이어/적 스폰)은 서버 전용 · 클라 빌드 미배포. 클라는 적의 존재를 S_EntitySpawn 패킷으로만 안다.

직업 쪽은 PlayerStats.MoveSpeed(4/6)가 정의만 있고 전 직업이 5.0을 쓰던 죽은 값을 실연결하고(MoveParams 필수 인자 — silent fallback 타입 차단), Animator·공격 전략을 ClassConfig SO lookup으로 장착해 조작 코드 직업 분기를 0으로 만들었다. Warrior(4) vs Ranger(6) 체감 차이는 의도된 정정.
