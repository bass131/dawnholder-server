## 2. 사용자 답 5건 (사실 박제)

| 항목 | 답 |

### 2.2 교수 면담 약속 (2순위)

5/20 면담 시 본인이 다음 발표(6/10)에 약속한 내용:

> "다음엔 **4맵 + 정밀 전투** 보여주겠다, **하나의 완성된 Flow**를 보여줄 것"

→ **약속 의미** (큰 트리거):
- 4맵 분리 인프라 = 의무
- 정밀 전투 (lag compensation + precision hitbox) = 의무
- 하나의 완성된 Flow = **시연 처음부터 끝까지 끊김 없이**
- 즉 **C 옵션 풀세트 의무**, (b) 다운그레이드 사실상 X

### 2.3 평가 기준 (3순위)

- 정해진 기준 **없음** (교수마다 다름)
- 확실한 거 = **교수 3명** 들어와서 평가

→ **균형 어필이 안전**. 한 영역 (예: 기술 깊이만) 압도적보단 *기능 완성도 + 기술 깊이 + UX* 골고루. 본인 약속 "완성된 Flow"가 *3명 모두에게 통하는 공약수* 정합.

### 2.4 슬라이드 박기 (4순위)

- **6/3까지 슬라이드 초안 마감** (교수 요구)
- **5/30부터 슬라이드 박기 시작** (코드 + 슬라이드 투트랙)

→ 코드 마감일 ≠ 6/10. 5/30부터 코드 가용 시간 ~50% 줄어듦.

### 2.5 정유현 협업

- 도와달라고 할 *수는 있음*
- 단 **실제 프로젝트 코드 작업은 같이 X**. 옆에서 알려주면서 진행 = 시간 더 뺏김. 득보다 실 ↑
- → **본인 단독 진행 확정**. 학부생 멘토링 정신 정합 (시기상조 협업 = 학습 비용 ↑)

### 2.6 가용 시간 정정 (큰 정보)

- **화/수/목 = 저녁 5시~밤 12시 (7h/일)**
- **나머지 (월/금/토/일) = 8시간 수면 + 식사 제외 = ~12~14h/일 풀타임**
- **총 가용 ~100h+** (19일 평균)

→ 옛 추정 25~27h는 *학부생 평균 가정*. 본인 풀파워 가용성이 *훨씬 많음*. **일정 위험 빠듯 → 낮음**. M4.1 + M4.2 + Demo 인프라 풀세트 *충분히 들어감*.

### 4.2 캐릭터 선택 디테일 (Phase 02 예정)

- **전사** = 근접 / 높은 HP / 낮은 이동속도 (예: HP 150 / Attack 15 / MoveSpeed 4)
- **원거리** = 활(원거리) / 낮은 HP / 높은 이동속도 (예: HP 80 / Attack 12 / MoveSpeed 6)
- **PDL 변경**:
  - `C_CharacterSelect { byte characterClass }` 패킷 신설 (Handshake 직후)
  - `enum CharacterClass : byte { Warrior=0, Ranger=1 }`
  - `S_HandshakeResult`에 캐릭터 선택 dispatch 분기 (또는 별 패킷)
  - **ProtocolVersion bump** (3 → 4 또는 5, M4.1 Phase 03과 정합 결정)
- **서버 스탯 분기**:
  - `PlayerStats { class, hp, attack, defense, moveSpeed }` (M4.1 Phase 02 Formulas.cs 박을 영역과 정합)
  - `EnterGameWorld` 시 캐릭터 클래스에 따라 default stats 박음
- **클라 UI**:
  - 캐릭터 선택 화면 (단순 2 버튼 — 전사/원거리)
  - 선택 후 마을 진입
