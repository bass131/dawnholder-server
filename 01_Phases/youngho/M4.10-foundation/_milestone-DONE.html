학습 하이라이트

  • 복붙은 언젠가 발산한다(실증) — roster 가드가 한쪽만 고쳐져 두 버전으로. 통합 = 발산을 물리적으로 불가능하게.
  • 추출의 핵심은 "무엇을 남기나" — 공통만 옮기고 경로별 차이는 호출처에. 차이를 끌고 들어가면 거동이 뭉개진다.
  • wire 불변 증명 2갈래 — struct diff 0(구조적, 현재 증명) + RoundTrip 테스트(미래 회귀 차단). 부수효과 순서는 수신 집합 disjoint를 손으로.
  • 선언=실재는 도구에도 — 문서가 SA1201과 반대 순서를 선언한 모순 발견 → 빌드가 검사하는 쪽이 진실(v6.1).
  • analyzer ≠ code-fix — dotnet format은 fixer 등록된 진단만 자동 수정. 멤버 이동은 의도적 미제공 → 수동.
  • DLL drift vs 정당 갱신 — 소스 무변경 재빌드 = drift(복원) / 소스 동반 = 정당(commit). 직전 git status가 판별 절차.
