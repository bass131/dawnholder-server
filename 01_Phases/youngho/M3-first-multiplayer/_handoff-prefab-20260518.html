M3 캐릭터 prefab 분담 — 지금 합의 (영호 ↔ 유현)

한 줄 요약: 5/20 면담 데모 목표 = "두 명이 같은 맵에서 보이는" 멀티. 그러려면 캐릭터를 prefab으로 만들어야 함. 영호가 골격(움직임 로직)만 박고, 유현이 비주얼(그림)을 살려내는 분담.

1. 용어 풀이 (이거 먼저)

prefab (프리팹)
"캐릭터 한 마리의 도면". Unity에서 같은 캐릭터를 여러 마리 만들 때 이 도면 하나로 찍어냄.
LocalPlayer (로컬 플레이어)
"내 캐릭터" — 내가 키보드로 직접 조종.
RemotePlayer (리모트 플레이어)
"다른 플레이어 캐릭터" — 다른 사람이 조종하는 거. 내 화면엔 그 사람 위치를 따라 그리기만 함.
("리모트" = "내가 원격조종"이 아니라 "원격에 있는 다른 사람"이라는 뜻. 헷갈리기 쉬워서 박아둠.)
placeholder (플레이스홀더)
"임시 자리표시" — 진짜 그림이 안 박힌 동안 자리만 잡는 회색 박스. 위에 entityId 숫자만 띄움.
컴포넌트 (Component)
"캐릭터에 붙어있는 기능 모듈". 예: 그림 모듈(SpriteRenderer), 애니메이션 모듈(Animator), 서버 위치 받아 부드럽게 따라가는 모듈(RemoteEntity).

2. 시간 순으로 화면이 어떻게 바뀌나

① 지금 (현재 게임 화면)

내 캐릭터

혼자만 보임. 유현이 만든 캐릭터 그림으로 이미 멋있음. 단 prefab은 아니고 씬에 직접 박힌 GameObject.

② 영호 Phase 05 끝나면

내 캐릭터
회색 박스 #1 회색 박스 #2

다른 플레이어들이 임시 회색 박스로 보임. 박스 위에 entityId 숫자만. 멀티 작동은 됨, 그림만 임시.

③ 유현 Phase 08a 끝나면

내 캐릭터
다른 캐릭터 다른 캐릭터

모두 진짜 캐릭터 그림. 면담 데모 도착점. 코드 변경 없이 prefab 비주얼만 교체.

3. 분담 표 — 누가 뭘 언제

단계누가무엇예상 시간
지금~Phase 05 영호
  • RemotePlayer.prefab 신설 (회색 박스 + entityId 라벨)
  • 이 prefab에 RemoteEntity 컴포넌트 박음 (서버 위치 받아 200ms 보간하는 모듈)
  • 서버 패킷 받아서 "다른 사람 들어왔네 → prefab 인스턴스 spawn" 흐름 박음
  • 다른 사람 나가면 → despawn
 3시간
그 다음 Phase 08a 유현
  • 씬 안 Player GameObject → LocalPlayer.prefab으로 추출 (M2 회귀 한 번 확인)
  • RemotePlayer.prefab의 비주얼만 진짜 캐릭터로 교체
    → 영호가 박은 RemoteEntity 컴포넌트는 절대 건드리지 X
  • (옵션) PlayerBase.prefab + variant 패턴 도입 — 학습 어필 ↑
 2시간

4. 합의 핵심 — RemotePlayer.prefab 안에 박힐 컴포넌트 4개

유현이 비주얼 작업할 때 RemoteEntity는 절대 건드리지 X. 나머지는 자유.

컴포넌트역할 (쉬운말)누구 영역
Transform캐릭터의 위치/회전/크기 (Unity 기본)공통
SpriteRenderer캐릭터 그림 그리기유현 자유 편집
Animator대기/이동 애니메이션유현 자유 편집
RemoteEntity ★ 보존 필수서버에서 받은 다른 사람 위치를 200ms 보간해서 부드럽게 따라가는 핵심 모듈영호 영역

5. 지금 합의할 항목 4개 (OK/NO만)

① prefab 이름

② 폴더 위치

③ 분담 = 영호 골격 + 유현 비주얼

④ (옵션) PlayerBase.prefab + variant 패턴

주의 — 유현이 LocalPlayer.prefab 추출할 때: 씬 안 Player GameObject의 컴포넌트 6개가 전부 보존되어야 함:

Transform · SpriteRenderer · PlayerInput · LocalPlayerController · Animator · PlayerAnimatorSync

추출 후 M2 회귀 한 번 (혼자 접속해서 캐릭터 WASD 조종 + 애니메이션 정상) 통과 확인.
유의 — 영역 충돌 한 군데: 영호 Phase 05에서 UnityClientSession.cs와 LocalPlayerController 인접 영역 건드림. 유현 영역 직접 X (CODEOWNERS상 영호 영역)지만 비주얼 컴포넌트 wiring 안 깸 약속. 의심되는 변경 있으면 디스코드 박기.
