# P4 2클라 수동 체크리스트

> **⚠️ 자동 회귀가 아님 — 영호 수동 수행 전용.**
> 이 문서는 bot·xUnit이 도달할 수 없는 맹점(클라 Predict 시각 연출)을 사람 눈으로 메운다.
> P4(로컬 예측 고정스텝 전환) **착수 전** "P4 전 거동" 컬럼을 채우고,
> P4 **완료 후** "P4 후 거동" 컬럼을 채워 판정한다.

---

## 수행 환경

- Unity Editor Play Mode (Gameplay씬) + 로컬 서버 실행 중
- 캐릭터 클래스: Knight (기본)
- 측정 기준: 눈으로 끊김·튐·위치 어긋남 유무 확인

---

## 체크리스트

| 항목 | 절차(구체 조작) | P4 전 거동(기입란) | P4 후 거동(기입란) | 판정 |
|------|---------------|-------------------|-------------------|------|
| **rubber-band** | 1. 오른쪽 키를 3초 동안 누른다. 2. 도중 서버가 위치를 보정할 때 캐릭터가 뒤로 튀는 현상 유무 확인. | | | |
| **Dash lunge** | 1. Knight Dash 스킬(기본 키)을 발동한다. 2. 전방 돌진 시 이동이 끊기거나 텔레포트처럼 보이는지 확인. 3. 같은 동작을 3회 반복. | | | |
| **평타 lunge** | 1. 적 앞에서 평타 공격을 입력한다. 2. 스윙 중 미세 전진 연출이 부드럽게 보이는지, 끊기거나 반대방향으로 뛰는지 확인. 3. 3회 반복. | | | |
| **피격 넉백** | 1. 몬스터에게 일부러 맞는다. 2. 넉백 후 캐릭터 위치가 부드럽게 서버 권위 위치로 복귀하는지 확인. 3. 2회 반복. | | | |
| **창드래그(P1 desync)** | 1. 윈도우 제목 표시줄을 잡아 드래그한다(실제 창 이동). 2. 드래그 중 또는 직후 캐릭터가 서버 권위 위치에서 벗어나거나 스냅 텔레포트가 일어나는지 확인. — *이 항목은 P1에서 관찰된 desync 증거 사슬의 수동 검증점.* | | | |
| **정지 떨림** | 1. 아무 키도 누르지 않고 5초 가만히 서 있는다. 2. 캐릭터가 제자리에서 미세하게 흔들리거나 Y축으로 진동하는지 확인. | | | |

---

## 판정 기준

- **Pass** — P4 전과 동일하거나 더 나은 연출. 명백한 시각 회귀 없음.
- **Fail** — P4 전에는 없던 끊김·텔레포트·반대방향 튐·떨림이 P4 후 관찰됨.
- **Note** — 조건부 재현(특정 프레임레이트·화면 크기에서만). 환경 기록 첨부.

---

## 수행 시 참고

- 서버 로그에서 `[Trust]` 또는 `desync` 키워드가 뜨면 함께 캡처.
- 재현 안 되는 항목은 "재현 불가" + 수행 환경(fps, 해상도) 기록.
- P4 완료 후 이 체크리스트를 채워서 `03-regression-safety-net-DONE.md`에 링크.
