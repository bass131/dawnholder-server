🤔2. 왜 필요한가

분산된 입력 차단 → 시스템적 게이트

동작 State가 끝나야 다음 입력을 받는 예외가 기술마다 재발했고, 차단 장치가 세 곳(이동 잠금 / 쿨다운 / 클래스)에 흩어져 있었다. 그 틈으로 Dash commit window 중 평타 진입 → Attack→Attack self-transition no-op → LungeDecayPerTick 0.85 잔류 버그.

상태가 자기 데이터를 소유

봉합이 "호출자가 평타 진입마다 기본값을 직접 세팅"이라 — 호출자가 상태 내부값을 찔러 넣는 구조 자체가 원인이었다. 게이트 + 상태 소유가 임펄스 재설계(P2~P6)의 서버 토대다.
