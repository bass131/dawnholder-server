🤔2. 왜 필요한가

화면의 완성 — 데모 클라이맥스
Phase 04까지 보스 전투의 논리는 서버에 완성됐지만 화면엔 아무것도 안 보였다. HP 바는 mock 값(M3부터 세 마일스톤 생존), 원격 플레이어는 직업 무관 단일 모습. 이번 Phase로 "맞고 / 보이고 / 죽고 / 살아나는" 루프 전체가 시각화됐다.
직업 시각의 단일 출처 — drift 구조 차단
중간 산출이던 v1(직업×Local/Remote = variant 4개)은 Knight 모습이 두 prefab에 중복 — 한쪽만 고치면 본인 화면과 타인 화면이 달라지는 drift 구조였다. 사용자 지적으로 재설계: 로직 껍데기(base) / 직업 비주얼(직업당 1개) 분리. 헌법 #1 정합 — 클라는 표시만, 데미지/HP 계산 코드 0줄.
