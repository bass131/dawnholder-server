Orca 감독형 worker · 외부 연동 문제

작업 수행 미통과

Orca 1.4.216의 앱·runtime 연결은 정상입니다. Astra worker와 Codex 0.159.0 초기 화면까지 실행됐지만 provider 준비 상태를 보고받지 못해 agent_readiness / timeout으로 실패했습니다. Task 미전달로 worker_done은 검증하지 못했습니다.

성공·실패·정리 범위
  • 요청/적용 모델은 모두 gpt-6-astra. timeout은 60초이며 무작정 재기동하지 않았습니다.
  • 공식 recovery로 이번 worker만 release, 보관 출력 확보, reclaimable 0, 기존 메인 터미널 하나 유지. 수신 delivery가 없어 ack 대상도 없었습니다.
  • 일반 서브에이전트 구현·검증이 동작하는 것과 실제 Orca 감독 연동 성공은 별개입니다.
  • 상세 상태와 재검증 조건 · 원본 시작 응답 (이 PC TEMP)
  • Run run_85f26e01d393 · Dispatch ctx_7e635e1b1d19. 버전·연동 수정 후 제한된 worker 한 개로 작업·완료 수신·정리 전 과정을 다시 확인해야 합니다.
