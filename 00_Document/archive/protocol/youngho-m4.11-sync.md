# 동기화 시계와 고정 스텝 — M4.11-sync

원래 작업 묶음: `01_Phases/youngho/M4.11-sync`. 주영역은 protocol이며 관련 영역은 client, server이다.

## 문제와 변경

원격 보간을 serverTick 기준으로 맞추고 고정 스텝 예측으로 전환했다. 단계별 회귀와 실제 두 클라이언트 확인을 구분해 기록했다.

## 작업별 근거와 남은 조건

요지는 원문의 요약·목표와 검증·제약 부분을 짧게 뽑은 것이다. 수치와 상태는 해당 문서 시점의 기록이며 현재의 완료 여부를 뜻하지 않는다. 계획을 통과 결과로 바꾸지 않았고, 다른 시점의 결과도 합산하지 않았다. 전체 수치·사용자 인용·후속 갱신은 고정 원문에서 확인한다.
