# 영역별 작업 이력

과거 작업과 운영 기록을 관심 영역별로 요약했다. 원문은 고정 커밋에 보존하며 현재 작업 지침은 [AGENTS](../../AGENTS.md), 현재 기술 문서는 [문서 지도](../INDEX.md)를 따른다.

| 영역 | 내용 |
|---|---|
| [서버](server/INDEX.md) | 맵·전투·파티·퀘스트와 서버 검토 |
| [클라이언트](client/INDEX.md) | UI·예측·아트·사운드 |
| [프로토콜](protocol/INDEX.md) | 패킷·입력 경계·동기화 |
| [도구·실행](tooling/INDEX.md) | 빌드·데모와 검증 도구 |
| [작업 운영](workflow/INDEX.md) | 폐기된 운영 정책·지식 관리·협업 방식 |
| [공통 구조](cross-cutting/INDEX.md) | 아키텍처·컨벤션·여러 영역의 리팩토링 |

## 원문 추적

- 기존 조사 500파일과 knowledge 운영 2파일을 [원문 매니페스트](source-manifest.json)에 기록했다. 현재 보고서 2개는 유지하며 이동하지 않았다.
- Phase 자료는 주영역별 36개 묶음으로 정리했다. 다른 영역 색인에는 같은 요약을 가리키는 링크만 두었다.
- [링크 매핑](link-map.json)은 이전 경로를 요약 파일·anchor와 고정 Git 원문으로 연결한다.
- SHA-256은 고정 Git blob의 원본 바이트 기준이다. Windows 줄바꿈 변환 전후 차이를 구분하기 위해 최초 조사 작업트리 해시도 별도로 보존했다.
- 고정 기준: [`59c7f087dc630df79650cedc3ede29765397bd8d`](https://github.com/bass131/dawnholder-server/tree/59c7f087dc630df79650cedc3ede29765397bd8d).
- 원문별 날짜·PR·커밋·상태와 발췌 근거를 남겼다. 모든 수치·인용을 요약에 옮긴 것은 아니며 전문은 고정 원문에서 확인한다.
- `ADR/harness`의 기술 결정 021·027·028·029는 현행 기술 검토 대상으로 원래 경로에 유지했다. 그 밖의 ADR도 이번 압축에서 삭제하지 않았으며, 매니페스트에 지정된 옛 운영 ADR 13개만 이력 요약으로 연결했다.
