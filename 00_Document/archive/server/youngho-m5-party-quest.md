# 파티·공유 퀘스트·포탈 — M5-party-quest

원래 작업 묶음: `01_Phases/youngho/M5-party-quest`. 주영역은 server이며 관련 영역은 client, protocol이다.

## 문제와 변경

맵을 넘는 파티 actor, 공유 킬 집계, 서버 포탈 잠금과 클라이언트 UI를 구현했다. 마감 v15/40킬과 후속 v16/20킬 기록을 구분한다.

## 작업별 근거와 남은 조건

요지는 원문의 요약·목표와 검증·제약 부분을 짧게 뽑은 것이다. 수치와 상태는 해당 문서 시점의 기록이며 현재의 완료 여부를 뜻하지 않는다. 계획을 통과 결과로 바꾸지 않았고, 다른 시점의 결과도 합산하지 않았다. 전체 수치·사용자 인용·후속 갱신은 고정 원문에서 확인한다.
