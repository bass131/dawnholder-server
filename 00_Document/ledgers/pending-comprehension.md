# Pending Comprehension — 깊은 학습 미룸 장부

> 루프가 *빨리 구현하고 넘어간* 것 중 영호가 **아직 깊게 안 본** 항목. 구현은 루프(흐름 안 끊김), 깊은 학습은 *별도 pull 세션*으로 분리 ([ADR-032](../ADR/harness/ADR-032-loop-driven-operation.md) §D). [`/session:review`](../../.claude/commands/session/review.md)에서 소비 — "이거 어떻게/왜 구현했어?".
>
> ⚠️ **이해 부채의 유일 방어 = 이 장부의 가시성.** "나중에 봐야지"가 안 일어나면 부채가 조용히 쌓임(ADR-025가 죽인 트랙 B 함정). 그래서 *가시 장부 + pull-분리*. 위치·운영 = [`INDEX.md`](INDEX.md).
