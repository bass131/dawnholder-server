# ADR-031 — Phase 자동 진행 + 보고 비동기 문서화 (학습 호흡 수동 멈춤 폐기)

- **상태**: accepted
- **날짜**: 2026-06-14
- **결정자**: 유영호 (하네스 단독 통제)
- **관련**: ADR-025 ("학습 호흡 명분 소멸" 이미 선언 — 본 ADR이 CLAUDE.md 드리프트 봉합 + 보고 모델까지 확장) / ADR-015 (post-flight 게이트 — "학습 호흡 보존" 명분 supersede, 형식 강제 훅 자체는 유지) / ADR-022 (5단계 보고 대규모 한정 — 임계·출력방식 갱신)

---

## 맥락 (왜 바꾸나)

ADR-025(2026-05-24)가 이미 **"'학습 호흡' 전제 소멸 — Phase 단위 수동 멈춤의 학습 명분이 사용자에게 더는 의미 없음(목표가 '배우기'→'밀기'로 이동)"**을 명시했다. 그러나 그 sweep이 불완전해, `CLAUDE.md:69`("다음 Phase로 수동 이동 — 학습 호흡 유지")를 비롯한 여러 곳에 **옛 문구가 드리프트로 잔존**했다.

M4.14 실측에서 두 단점이 부각됨:

1. **흐름 잦은 끊김**: 매 Phase 경계마다 "다음 갈까요?" 멈춤 → 자율 진행 가능한 작업도 사용자 왕복 대기. 학습 명분이 죽은 마당에 *공학적 이득 없는* 흐름 끊김만 남음.
2. **인라인 보고의 흐름 비용**: 대규모 Phase 완료 시 인라인 5단계 보고 출력이 작업 흐름 한가운데를 끊음. 보고는 *사용자가 원할 때 비동기로* 확인하는 게 정합.

## 결정

| 항목 | 전 | 후 |
|---|---|---|
| Phase 진행 | 다음 Phase로 **수동 이동** (학습 호흡) | **자동 진행**. Stop은 *영호 직접 확인/결정 지점*에서만 |
| Stop 조건 | 매 Phase 경계 | ① 비가역(push/merge/`Protocol.Version` bump/DB 마이그) ② 설계 분기(영호 결정 필요) ③ 승인 게이트(예: convention sweep 적용 전 diff 승인) ④ 육안 검증(Unity 외관) |
| 작업 보고 | 대규모 = 인라인 5단계 보고 출력 | **비동기 문서**: 인라인 출력 폐지, `-DONE.md` + HTML 시각화 *문서 안*에 5단계 보고 구조 박제 |
| HTML 시각화 임계 | 대규모만 | **복잡 이상** (복잡도 캡스톤 평가 자산 가치 충분) |
| 권유(학습 박제/세션 마감) | `-DONE.md` commit 직후 매 Phase | **마일스톤 마감 또는 영호 직접 확인 지점**에서만 |

**공학 게이트는 유지**: 회귀(WSL2 test/EditMode)·drift(work-pin)·trust-boundary 기계검증은 *자동 점검 후 진행*(멈추지 않음). 비가역 게이트(PR/merge = 영호 GO)는 ADR 불변 — 그대로 Stop.

## 결과

- **얻음**: 작업 흐름 연속성 ↑ (자율 진행 가능분은 멈춤 없이), 보고가 흐름을 안 끊음, 캡스톤 자산(HTML)이 복잡 등급까지 확대.
- **잃음**: Phase별 사용자 체크포인트의 *세밀함*. → 비가역·설계·승인·육안 4종 Stop이 안전망 유지(공학적 명분만 남김 = ADR-025 정신 정합).
- **supersede / 갱신**:
  - ADR-015의 "학습 호흡 보존" 명분 무효 (형식 강제 훅 자체는 유효 — 훅이 Phase를 *자동 실행*하진 않음).
  - ADR-022의 "5단계 보고 = 대규모 인라인" → 복잡 이상 문서 내장으로 갱신.
- **헌법/정책/훅 sweep 동반** (dangling 참조 0):
  - `CLAUDE.md` "작업 보고" + "작업 좌표/Phase 완료 박제" + "01_Phases 다음 Phase" + "작업 등급 표 보고 양식 열" 4곳.
  - `policies/{reporting-format,grade-and-risk,pin-and-done}.md` (임계·표·라이프사이클).
  - `commands-index.md` (/session:end 등급별 분기 + 트리).
  - `.claude/hooks/phase-gate-validator.sh` (5단계 보고 + HTML 페어 강제 = 대규모 → **복잡 이상**).
  - `ADR-015` + `REVIEW_CHECKLIST.md` 참조 정정.

## 한계 / 모니터링

- **HTML 부담 ↑**: 복잡 Phase가 대규모보다 잦아, 매 복잡 -DONE.md에 HTML 페어 의무 = 작성 비용 ↑. MD→HTML 변환 스크립트(`99_Tools/`) 자동화 후보 우선순위 상승. 비용이 가치 추월 신호 잡히면 재조정.
- **Stop 누락 위험**: 자동 진행이 *영호가 보고 싶던 지점*을 지나칠 수 있음 → 4종 Stop 조건을 보수적으로 해석(애매하면 Stop). 비가역은 절대 자동 진행 X.
