### ADR-018: 하네스 망각 안전망 — 작업 봉투 + 핀 + WORK-ID
**날짜**: 2026-05-12
**상태**: 채택됨 (단, M3.5 Phase 06 / ADR-022로 *부분 superseded*: 작업 봉투(work-envelope) 양식 죽임 + `check-work-envelope.sh` Hook 삭제 + `inject-current-pin.sh` → `pin-injector.sh` rename. **WORK-ID 마커링 + 작업 좌표 핀 정신 자체는 유지** — 새 운영에서도 핵심 안전망. 새 양식 = 등급별 보고 분기 + work-pin ↔ CONTEXT 정합 게이트 옵션 C로 발전. 디테일은 ADR-022 참조.)
**결정**: AI 컨텍스트 디케이(세션 후반 헌법·보고 약속 망각) 해소를 위해 **입구·출구 한 짝 안전망**을 도입. (1) **출구 = 작업 봉투**: Edit/Write/MultiEdit를 한 번이라도 호출한 응답 끝에 `<!-- work-envelope --> ... <!-- /work-envelope -->` 마커 + 4 헤더(`변경:` / `검증:` / `남은 것:` / `학습 포인트:`) + WORK-ID를 첨부. `Stop` 훅 `.claude/hooks/check-work-envelope.sh`가 transcript에서 도구 사용 + 봉투 누락을 grep으로 감지(stderr 경고만, 차단 X). (2) **입구 = 작업 좌표 핀**: `.claude/state/current-pin.txt`에 진행 상태(WORK-ID + 8~12줄: PHASE / 현재 작업 / 완료 조건 / 다음 액션 / 주의할 약속 / 학습 보존 / 마지막 갱신) 보관. `UserPromptSubmit` 훅 `.claude/hooks/inject-current-pin.sh`가 매 사용자 입력 직전 핀 내용을 stdout으로 출력해 컨텍스트 상단 주입 — 학습 질문 끼어들어도 다음 턴에 작업 좌표 자동 복원. (3) **합류 = WORK-ID 마커링**: `phase05-snap-reconcile` 같은 slug를 핀·봉투·DONE.md·학습 일지에 동일하게 박아 산출물 그래프화 → `grep "<WORK-ID>"` 한 방으로 한 작업의 모든 흔적 회수 (면접·회고·이식 시 가치). 핀 갱신은 **"완료 조건/다음 액션 변경 시만"** AI 자동, 주의할 약속·학습 보존은 사용자 수동(잘못된 핀 고착 방지). 이식성 위해 `.claude/templates/pin-template.txt`에 빈 템플릿 별도 보관. 5단계 보고 / DONE.md는 *별개로* 그대로 유지 (봉투 ≠ Phase 보고 부분집합).
**이유**: 페인 진단 결과 자동화 트리거 부족이 아니라 *LLM context decay*(긴 컨텍스트에서 헌법·보고 약속의 attention 약해짐)가 진짜 원인. 망각에 *맞서기*(기억 강화)가 아닌 *피하기*(기억할 게 적게 + 안전망이 잡음)가 핵심. 입구·출구 한 짝이어야 세션 흐름 전체(입력 → 작업 → 출력)에 안전망 — 출구만으론 Phase 중간 학습 질문 끼어듦 시 작업 좌표 분실을 못 잡음. Codex CLI 3라운드 자문으로 (R1: 표준 봉투화 = 출력 계약 작게 / R2: LLM self-check 금지·매 응답 봉투 ≠ Phase 보고 부분집합 / R3: WORK-ID 마커링·핀 갱신 정책) 교차 검증. WORK-ID로 산출물 그래프화는 팀원 이식(헌법 5번 요구)에도 직결.
**트레이드오프**: 봉투 형식이 매 코드 응답에 강제 → 약간의 응답 길이 증가(허용 비용). 핀 자동 갱신이 잘못되면 옛 좌표가 매 턴 주입되어 *역효과* — "완료 조건/다음 액션 변경 시만" 갱신으로 제한. 입구 훅이 매 입력마다 ~10줄 추가 주입 → 토큰 누적 미미하지만 의식 필요. 보고 체계가 3중(봉투 / 5단계 / DONE.md) — 의도된 분리지만 초기 학습 적응 비용. Stop 훅은 LLM이 아닌 grep 기반이라 봉투 *형식*만 검사, *내용 품질*은 검증 못 함(R2 통찰 — self-check 위임은 같은 망각층 의존이라 의도된 한계). Claude Code transcript JSONL 포맷 의존 — 포맷 변경 시 훅 수정 필요.
