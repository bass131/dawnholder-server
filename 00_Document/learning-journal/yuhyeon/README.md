## 작성 방법

3가지 종류 (`00_Document/learning-journal/README.md` 참조):

- `/journal:phase` — Phase 끝날 때
- `/journal:concept <키워드>` — 깊이 판 개념
- `/journal:bug` — 막혔다가 풀린 사건

폴더 구조 예시:

```
yuhyeon/
├── README.md             (이 파일)
├── M1-{slug}/
│   ├── 01-{phase}.md
│   ├── concepts/
│   │   └── {keyword}.md
│   └── troubleshoots/
│       └── {YYYY-MM-DD}-{slug}.md
└── M2-{slug}/
    └── ...
```

마일스톤·Phase 이름은 `01_Phases/yuhyeon/` 구조와 1:1 맞추면 추적 쉬움.
