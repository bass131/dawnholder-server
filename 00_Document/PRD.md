# 제품 범위

Dawnholder는 친구들과 사냥하고 얻은 자원으로 길드 거점을 발전시키는 2D 사이드스크롤 RPG를 목표로 한다. 현재 결과물은 서버 권위 이동·전투와 파티 플레이를 구현한 PC 프로토타입이다. 길드 타이쿤은 제품 방향이며 현재 구현 완료를 뜻하지 않는다.

## 현재 구현과 후속 범위

| 구분 | 내용 | 확인 위치 |
|---|---|---|
| 구현 | 이동·점프, 예측·재조정, 원격 보간 | [기능 지도](FEATURE_MAP.md) |
| 구현 | 근접·원거리 전투, 스킬, 적·보스, HP·사망·리스폰 | [서버 시스템](../02_Server/GameServer/Maps/Systems/) |
| 구현 | 포탈 맵 이동, 파티 초대·수락·탈퇴, 처치 진행도·보스 진입 조건 | [Party](../02_Server/GameServer/Party/), [Quest](../02_Server/GameServer/Quest/) |
| 구현 | Unity 화면·입력·효과·음향과 헤드리스 봇 시나리오 | [클라이언트](../03_Client/Assets/Scripts/), [봇](../99_Tools/headless-bot/) |
| 미완료 | SQL 연결, 캐릭터·인벤토리 영속화, 재접속 복원 | [저장 경계](ARCHITECTURE.md#맵과-저장-상태) |
| 제품 방향 | 인벤토리·길드 창고, 길드·거점 시설과 성장 순환 | 새 목표에서 범위·순서를 별도로 합의 |

## 대상과 제한

친구들과 짧은 세션으로 즐기는 한국어 PC 게임과 서버·네트워크 포트폴리오를 지향한다. 상용 출시·결제, 모바일·콘솔, 대규모 심리스 월드, 복잡한 제작·경제 시뮬레이션은 현재 범위에 포함하지 않는다. 출시 기능이나 법적 요구사항을 생략해도 된다는 뜻은 아니다.

새 기능은 [현재 목표](operations/CURRENT.md)의 범위·완료조건에 포함한 뒤 진행한다. 옛 마일스톤 번호는 앞으로의 구현 순서를 정하지 않는다.

## 확인할 품질

서버 권위와 입력 검증, 이동·전투·맵·파티의 회귀, 사용자가 실제로 보는 Unity 동작을 구분해서 확인한다. .NET 빌드와 봇 통과만으로 Unity 외관·SQL 연결·실제 플레이 경험까지 통과했다고 보고하지 않는다.

과거 계획에는 3명 이상 30분 플레이, 1시간 안정성, 봇 100명에서 tick p99 10 ms 미만·메모리 증가 5% 이내·패킷 손실 1% 미만, 핵심 핸들러/공식 커버리지 100%·전체 60% 이상을 목표로 적었다. 이는 [당시 PRD](https://github.com/bass131/dawnholder-server/blob/59c7f087dc630df79650cedc3ede29765397bd8d/00_Document/PRD.md)의 목표 수치이며 달성 실적이 아니다. 재사용할 때 측정 방법과 현재 범위를 먼저 정한다.

제품·기술 결정과 과거 시연 범위는 [ADR](ADR/INDEX.md), [보관 기록](archive/INDEX.md)에 남긴다. 최신 검증 결과는 각 목표의 `goal.md`에서 확인한다.
