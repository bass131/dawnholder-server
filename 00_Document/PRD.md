## 한 줄 요약

**친구들과 사냥하고, 번 자원으로 우리만의 길드 거점에 시설을 사서 꾸미는
2D 사이드스크롤 캐주얼 RPG.**

핵심 차별점은 **액션 RPG와 길드 타이쿤의 결합** — 사냥 보상이 거점 성장으로,
거점 성장이 다시 사냥을 돕는 순환 구조.

## 목표와 비목표

### 🎯 Goals

**프로젝트**: 게임 회사 백엔드 포지션 포트폴리오 + 백엔드/네트워킹 실전 학습
(raw TCP, 권위 서버, 동시성, 영속화) + 데모/부하 테스트 결과/기술 블로그형 README.

**게임**: 친구들과 짧은 세션의 캐주얼 액션 + 길드 거점 소속감/성장 만족 +
두 루프(사냥/거점)의 의미 있는 연결.

### 🚫 Non-Goals (절대 안 만드는 것)

명시 안 하면 scope가 끝없이 늘어남. **이건 만들지 않는다**:

- **상용 출시** — 학습/포트폴리오. 결제, 보안 감사, GDPR 무시.
- **모바일/콘솔** — PC 윈도우 클라이언트만.
- **고품질 그래픽** — 무료 에셋 + placeholder 스프라이트 OK.
- **로컬라이제이션** — 한국어만.
- **자원 생산 시뮬레이션** — 시설은 "구매 → 기능 제공" 모델만 (NPC 고용/자원 변환/생산 라인 X).
- **거점 PvP / 영토전** — 거점은 길드별 안전 공간.
- **분산 서버 / 샤딩** — 단일 서버 프로세스로 100~500명 처리 (ADR-008).

### 🤔 Maybe Later

길드 간 PvE 경쟁 / 거점 풀 타이쿤화 / 인스턴스 던전 / 시즌제 콘텐츠.

## 핵심 기능 (MVP)

> MVP의 정의: **이 6개가 다 되면 데모 영상을 찍을 수 있다.**

1. **계정 + 캐릭터** — 닉네임 단순 로그인, 캐릭터 1개, 영속화(인벤토리/위치).
2. **이동 + 점프 ★** — 2D 사이드스크롤 + 클라 prediction + 서버 권위 +
   reconciliation + snapshot interpolation. **데모 영상의 절반.**
3. **사냥 + 전투 ★** — 근접 공격 1종, 몬스터 1~3종, 데미지/HP/사망/리스폰 모두
   서버 권위, 드랍(골드 + 재료), lag compensation 200ms.
4. **인벤토리 + 길드 창고 ★** — 개인 인벤토리(NN 슬롯) + 길드 창고 동시성 처리,
   아이템 이동/스택/버리기 모두 서버 권위 + 검증.
5. **길드 + 거점 ★** — 길드 생성/가입/탈퇴, 길드별 인스턴스 거점 맵, 시설
   구매/배치(모루/회복샘/창고 확장 등), 길드 자금 기여.
6. **마을 + 사냥터** — 공용 마을 1개, 사냥터 1~2개(오픈), 거점(인스턴스),
   맵 간 portal/handoff.

**MVP에 의도적으로 뺀 것**: 채팅, 친구/우편/거래, 직업/스킬 트리, 퀘스트/NPC,
업적/도감.

## 성공 기준

### 게임 차원
- 친구 3명 이상 동접 30분 플레이
- 마을→사냥터→거점→마을 한 사이클 끊김 없음
- 길드 5개, 시설 5종 이상
- 1시간 연속 플레이 안정 (메모리 누수/크래시 없음)

### 기술 차원
- 봇 동접 100명 부하 테스트 통과 (tick p99 < 10ms, 메모리 +5% 이내, 패킷 손실 < 1%)
- 권위 서버 위반 0건 (헌법 hook 자동 검출)
- 단위 테스트 커버리지: 핵심 핸들러/공식 100%, 전체 60%+

### 포트폴리오 차원
- README 기술 블로그 수준 (아키텍처 다이어그램, 핵심 문제 해결 서사 2~3개)
- 데모 영상 2분 이내 (사냥 + 거점 시퀀스)
- 부하 테스트 그래프 + 학습 일지 (노션/블로그)

## 🎓 캡스톤 1 발표 (2026년 6월 10일)

**중간 발표** — 본 마감(11월 19일)이 진짜 마감. 캡스톤 1 시점 = 본인 단독 작업
가정 (팀원 학습 마라톤은 6월 말 학기 후 시작).

### 데모 범위
- **옵션 C (Stretch, 목표)** — M3 풀세트(broadcast + 단순 전투 데모). 임팩트 강함.
- **옵션 B (Fallback)** — M2 도달, 1인 movement (권위 + prediction + reconciliation). 임팩트 보통.

→ **6주 안에 C가 안 되면 발표 직전 깔끔하게 B로 다운그레이드.** 자존심 빚 X.

### 중간 면담 (2026-05-20) — 응급 데모
캡스톤 1 직전 교수 면담 = M3 풀세트 응급 시연. 단일 맵 3-zone 트릭(마을/전투/보스 + Stage Clear UI)으로 *진짜 4맵 분리 인프라 부담 회피*. 본격 4맵 + 정밀 전투는 M4로 분리. 시연 위주 / 발표자료 병렬 작성. 헌법 #1(서버 권위) #3(신뢰경계) 단순화는 OK, 위반은 X.

### 코드 베이스 출발점
4월 학습용 ServerDev 코드 시나리오 B 부분 채택(ADR-011): ServerCore + PacketGenerator + PDL.xml
+ DummyClient 채택, 게임 로직과 Unity 클라는 새로 작성 (헌법 #1 Server Authority 적용).

자세한 근거 = ADR-001, ADR-002, ADR-010, ADR-011.
