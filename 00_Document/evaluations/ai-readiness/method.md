# AI Readiness 평가 기준

실밸개발자의 공개 `ai-readiness-cartography` v2를 적용한다. 공인 인증이나 Factory 점수가 아니다. 배점은 탐색 A 15, 문맥 품질 B 20, 암묵지 C 20, 의존 관계 D 15, 검증 E 15, 최신성 F 10, 실제 에이전트 결과 G 5다. 저자가 정한 등급은 75점부터 AI-Ready, 90점부터 AI-Native이며 이번 목표는 75점이다. 등급으로 미실행 검증이나 병합 권한을 대신하지 않는다.

## 측정 범위

개선 전은 `59c7f087dc630df79650cedc3ede29765397bd8d`의 추적 파일로 고정했다. 개선 후도 추적 파일과 이번에 추가한 문서·검증 도구만 별도 임시 폴더에 복사한다. 평가 산출물 자체는 제외한다. Unity Library, 빌드 산출물, 비공개 로컬 설정과 로그는 포함하지 않는다. 게임 실행이나 소스 수정 없이 원본 Python 스크립트를 실행한다. 스크립트의 외부 호출은 읽기 전용 Git 브랜치 조회뿐이며 지정한 결과 JSON 외에는 쓰지 않는다.

원본 자동 점수와 근거를 확인한 수동 보강 점수를 함께 남긴다. 원본 스크립트는 수정하지 않는다. 원본은 중앙 문서·숫자 디렉터리·PowerShell·.NET·한글 경로·`.githooks`를 충분히 인식하지 못하며 `.agents`의 점을 떨어뜨리는 경로 오탐도 있다. 스냅샷 mtime은 문서 최신성 근거가 아니므로 F의 수동 보강에는 Git 변경 기록·문서 검증 기록·실제 검사 도구만 사용한다.

## 전후 공통 판정

- A: 다섯 코드 영역(Server, Unity, ClientNet, Shared, Tools)의 역할·진입점·연관 경로를 현행 진입 문서에서 찾을 수 있는지 확인한다. 특정 파일 이름을 만들었다는 이유만으로 가산하지 않는다.
- B: 저자의 다섯 소항목을 각 4점으로 평가한다. 0은 없음, 1은 단편, 2는 사용 가능하나 반복·누락이 큼, 3은 대부분 충분하나 확인된 결함이 있음, 4는 실제 작업에 충분하고 확인한 결함이 없음이다. 짧은 루트 안내와 필요할 때 읽는 상세 문서를 하나의 진입 구조로 본다.
- C/D/F: 원문의 단계별 기준으로 판단한다. 역사 자료는 근거가 될 수 있지만 현재 규칙과 섞이면 감점한다. F는 수동 갱신 3점, 일부 자동 검사 6점, 주기적 탐지·수정까지 확인된 경우만 10점이다.
- E: 경로 정확성 5, 독립 검토 4, 작업 검증 4, 대표 AI 작업 검증 2점이다. 파일 존재만으로 실행 통과를 인정하지 않는다. 확인하지 못한 Unity·DB·새 세션 동작을 따로 남긴다.
- G: 결과 측정이 없으면 0점이다. 이 평가표나 일반 게임 테스트를 에이전트 성능 측정으로 세지 않는다. 실제 대표 작업 성공률은 3점, 도구·시간·토큰·정확성 전후 측정까지 있어야 5점이다.

수동 보강은 평가자의 판단이며 제품이 발급한 점수가 아니다. 전후에 이 기준을 바꾸지 않는다. 원본이 제안하는 시간·토큰 절감 추정치는 Dawnholder의 실측 결과로 인용하지 않는다.
