# 기술 결정 기록

주요 구조・계약・기술 선택은 [ADR 색인](ADR/INDEX.md)에서 찾는다. 현재 운영 기준은 [AGENTS](../AGENTS.md)다. 옛 운영 ADR과 후보 번호를 현재 요구사항으로 자동 적용하지 않는다.

되돌리기 비용이 큰 결정을 기록할 때 번호・날짜・상태, 선택한 내용, 이유, 검토한 대안과 비용을 남긴다. 기존 결정을 대체하면 이전 번호와 관계를 명시하고 색인에서 찾을 수 있게 한다. 단순 구현 변경마다 ADR을 만들 필요는 없다.

실제 구현 위치는 [기능 지도](FEATURE_MAP.md), 이전 운영 결정은 [workflow 보관](archive/workflow/INDEX.md), 결정 이력은 [ADR_History](ADR_History.md)에서 확인한다.
