# GPP 레퍼런스 색인

## 이 폴더 사용법

SubAgent가 패턴을 검색하거나 설계 결정을 내릴 때 이 파일을 **진입점**으로 쓴다. 흐름은 다음과 같다.

1. 아래 카테고리 표에서 현재 문제와 맞는 패턴 행을 찾는다.
2. "언제 참조" 열로 적합 여부를 빠르게 확인한다.
3. 해당 파일 링크를 열어 "우리 프로젝트 적용" 절을 읽고 코드 레벨 판단을 내린다.

각 파일은 핵심 내용 + 프로젝트 적용 예 + 함정/과용 경계 + 관련 패턴으로 구성되어 있다.
설계 결정의 *근거*가 필요할 때 해당 파일의 "언제 쓰고, 언제 안 쓰나" 절이 trade-off를 담고 있다.

## 카테고리 간 자주 쓰이는 조합

- **God class 분리**: Component(13) + Event Queue(14) + Update Method(09)
- **Enemy AI 확장**: State(06) + Type Object(12) + Update Method(09)
- **틱 루프 최적화**: Game Loop(08) + Object Pool(18) + Data Locality(16)
- **네트워크 패킷 구조**: Command(01) + Event Queue(14) + Double Buffer(07)
- **전역 서비스 제공**: Singleton 대신 Service Locator(15), Singleton 문제 이해는 05
