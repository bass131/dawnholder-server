# CHANGELOG — 하네스 변경 이력

> **이 파일의 역할**: 영호가 헌법/ADR/하네스/공유 파일을 변경할 때마다
> 한 줄씩 박제. compact·세션 경계에서 `/session:start`가 최근 줄을 자동으로
> 보여줘서 옛 결정 기반으로 작업하는 사고 예방 (solo — 세션 간 기억 대체).
>
> **갱신 주체**: 영호 단독 (변경=영호, AI는 commit 직후 박제 권유).
>
> **갱신 규칙**:
> - 변경 commit 직후 한 줄 추가
> - 형식: `YYYY-MM-DD — 한 줄 요약 (영향 범위 / 위험도)`
> - 위험도 표기: `[L]` (저위험, 추가만) / `[M]` (중간, 행동 변경) / `[H]` (고위험, 결정 뒤집기)

---

## 갱신 룰 짧게

**저위험 [L]** — 새 슬래시 커맨드, 새 서브에이전트, 새 ADR 박제 (기존 결정 변경 X), 학습 일지 템플릿 보강
**중간 [M]** — 슬래시 커맨드 동작 변경, 기존 ADR 사후 보강, 헌법 일부 섹션 추가
**고위험 [H]** — 헌법 절대 원칙 수정, 기존 ADR 뒤집기 (PostgreSQL→MSSQL 같은 결정 정정), 파일 권한 분리, 영역 분리 변경

[H]는 결정 뒤집기라 commit·CHANGELOG에 사유 명확히 박고 신중히 진행 (solo — 외부 공지 대상 없음).
