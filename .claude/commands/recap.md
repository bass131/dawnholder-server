사용자가 현재 위치 정리를 요청했습니다.

다음을 수행하세요:

### 1. 프로젝트 상태 스캔
- `git log --oneline -20`으로 최근 커밋 확인
- 주요 디렉토리(`02_Server/`, `03_Client/`, `98_Shared/`) 트리 훑어 어디까지 만들어졌는지 파악
- 마지막 작업 컨텍스트가 뭔지 파악

### 2. 사용자에게 보여줄 보고

```
─────────────────────────────────────────
📍 현재 위치 정리
─────────────────────────────────────────

✅ 지금까지 완성된 것
- [기능 1]: 한 줄 설명
- [기능 2]: 한 줄 설명
...

🚧 진행 중이거나 부분만 된 것
- [기능 X]: 어디까지 됐고 뭐가 남았는지
...

📚 학습한 주요 개념
- 개념 1: 한 줄 요약
- 개념 2: 한 줄 요약
...

➡️ 추천 다음 작업 (우선순위 순)
1. [작업 A]: 왜 이게 다음으로 좋은지
2. [작업 B]: 대안
3. [작업 C]: 미래에 할 일

🤔 결정 보류 중인 것
사용자가 답을 미뤄둔 디자인 결정이 있다면 여기 나열.

❓ 메모/주의사항
- 마지막 세션에서 미해결로 남은 질문
- 알아두면 좋을 함정
```

### 3. 마지막 한마디
"오늘은 [추천 작업]부터 시작하면 좋을 것 같아요. 다른 걸 하고
싶으시면 말씀해주세요." 같은 부드러운 가이드.
