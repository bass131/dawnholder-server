사용자가 다음 개념의 학습 일지 작성을 요청했습니다:
**$ARGUMENTS**

**핵심 원칙**: 본인이 진짜 이해한 만큼만 적기. AI가 채우면 가짜 학습.
"잘 모르는 부분"으로 적는 것도 학습의 흔적.

다음 절차를 따르세요:

### 1. 컨텍스트 수집
- 이 개념이 우리 프로젝트 어디에 등장했는지 grep
- 직전 `/learn:concept`, `/learn:explain` 결과가 있으면 참조
- 관련 Phase 파일도 확인

### 2. 일지 파일 위치
- 경로: `00_Document/learning-journal/M{N}-{milestone}/concepts/{slug}.md`
- 어느 마일스톤 소속인지 사용자에게 물어볼 수도 (애매하면)
- 이미 있으면: "갱신할까요? 어느 부분?"

### 3. 템플릿 + 자동 채우기 + 인터뷰

`00_Document/learning-journal/_template-concept.md` 베이스.

**자동 채워도 OK** (메타 정보):
- 작성일
- 등장 Phase
- 우리 코드의 실제 등장 위치 (grep으로 찾은 파일+라인)

**인터뷰로만 채울 항목** (본인 이해도):
- 한 줄 정의
- 처음 만난 맥락 (감정/동기)
- 비유로 이해하기
- 정확한 설명 (단계적)
- 흔한 오해
- 면접 시뮬레이션
- 이해도 자가평가

### 4. 인터뷰 모드

질문 하나씩, 답 받으면 다듬어 채움.

1. **한 줄 정의**
   "이 개념을 모르는 친구에게 한 문장으로 설명한다면?"
   → 답 받음. **너무 짧으면 더 풀어보라 권유.**

2. **처음 만난 맥락**
   "이 개념은 왜 우리 프로젝트에 등장했어요? 어떤 상황에서 필요했죠?"

3. **비유**
   "일상의 비유 하나만 만들어보세요. 완벽하지 않아도 돼요."
   → 답 받으면 "이 비유의 한계는 뭐일까요? 비유가 안 맞는 부분?"
   추가 질문. **이게 진짜 이해의 신호.**

4. **단계적 설명 — 표면**
   "본인 말로 설명해주세요. 우선 가장 표면적인 수준부터."

5. **단계적 설명 — 한 단계 깊이**
   "한 단계 더 깊이 가면? 메커니즘 차원에서."
   → 답 못 하면 "🟡 대략 이해" 또는 "🔴 표면만"으로 평가하고 학습 큐에 추가.

6. **흔한 오해**
   "이 개념에 대해 본인이 헷갈렸거나, 다른 사람이 헷갈릴 만한 게 있나요?"
   → 본인 헷갈림 = 학습의 진짜 흔적. 적극 적기.

7. **우리 코드에서의 사용**
   - AI가 grep으로 찾은 위치를 보여주고
   - "여기서 이 개념이 어떻게 쓰이고 있는지 본인 말로 설명해보세요."

8. **면접 시뮬레이션**
   "이 개념 관련해서 면접에서 받을 만한 질문 1개 떠올려보고 답해보세요."

9. **이해도 자가평가**
   "🟢 잘 이해 / 🟡 대략 / 🔴 표면 — 솔직히 어느 쪽?"
   → 솔직한 자가평가가 학습의 시작. "🔴" 답해도 OK.

### 5. 마무리

```
─────────────────────────────────────────
✅ 개념 학습 일지 저장됨: [개념명]
─────────────────────────────────────────

📍 파일: 00_Document/learning-journal/M{N}/concepts/{slug}.md

🎓 자가 평가: 🟢/🟡/🔴

📚 학습 큐에 추가된 것:
- [더 깊이 알고 싶은 점]
- [흔한 오해 검증]

📝 블로그 발전 가능성: 예/아니오
   → 가능성 있으면: "다이어그램, 코드 비교 등 추가 자료 모이면
     포트폴리오 차원에서 글로 만들기 좋아요."

➡️ 다음 액션:
- 자가 평가 🔴/🟡면: 더 학습 후 갱신
- 자가 평가 🟢이고 블로그 발전 가능: 글로 발전 가능성 메모
- 다음 Phase로
```

### 6. 톤

- **자가평가에서 솔직함 권장**. "🔴 표면만"이라 답하면 "그것도 학습의 시작이에요"
  반응. 과장하지 않기.
- **AI가 이해 도와주려는 욕구 절제**. 본인이 모르는 부분은 모른다고 적게.
  AI가 채워주면 가짜 학습.
- **"나중에 갱신" 권장**. 지금 부족하면 미래의 본인이 채울 빈칸으로 둠.
