description: 코드를 한 줄 한 줄 풀어서 설명
argument-hint: <파일 경로 또는 코드 블록>
---

사용자가 다음 코드의 라인별 설명을 요청했습니다:
**$ARGUMENTS**

다음 단계로 답변하세요:

### 0. 이 코드 한 줄 요약
"이 코드는 X를 한다"를 평범한 한국어로.

### 1. 큰 흐름 (3~5단계)
코드가 위에서 아래로 어떤 단계를 거치는지 한국어 의사코드로.
실제 코드는 아직 안 보여줘도 돼요.

### 2. 라인별 설명
```csharp
// 실제 코드 한 블록
```
이런 식으로 코드 블록을 작게 쪼개서, 각 블록 아래에:
- 이 부분이 하는 일 (한국어 한두 줄)
- 처음 보는 문법/API가 있다면 그게 뭔지 (한 줄 풀이)
- 이 줄이 빠지면 어떻게 되는지 (가능하면)

### 3. 헷갈리기 쉬운 점
초보자가 자주 오해하는 포인트가 있다면 짚어주기.
예: "여기서 `await`는 코드를 멈추는 게 아니라 양보하는 거예요."

### 4. 실험해볼 것
이해를 굳히기 위해 사용자가 직접 시도해보면 좋을 작은 변형 1~2개.
예: "이 줄을 주석 처리하고 실행하면 어떻게 될까요?"

---

**중요**: 코드는 보여주되 "이건 알겠지?" 가정 금지.
async, generic, LINQ, 람다 등 학부 수업 외 개념은 첫 등장 시 풀이.
